# AF/G.23 — Final 14 gap countries: municipal-tier depth complete for all of Africa, 2026-08-13

## Orientation

Direct continuation of AF/G.22, opened by Thomas's instruction "lets finish off africa" — the shortest possible pointer at AF/G.22's own closing list of the 14 remaining gap countries (those with a base CPI/statistics node but no municipal/sub-national fiscal-tier depth): Namibia, Gambia, Gabon, Botswana, Lesotho, Guinea-Bissau, Equatorial Guinea, Eswatini, Mauritius, Djibouti, Comoros, Cabo Verde, São Tomé and Príncipe, Seychelles. This session dispatched 14 parallel research agents (one per country) against `AF/AF-municipal-tier-protocol.md`'s standard dispatch template, then 14 parallel synthesis agents to turn those findings into corpus JSON. A mid-session context compaction happened between the research and synthesis steps — as in AF/G.22, the research agents' full findings were **not lost**: all 14 were recovered verbatim from this session's own transcript file (`~/.claude/projects/.../<session>.jsonl`, extracting each Agent tool call's `tool_result` content by its `tool_use_id`) rather than re-researched. This is a cleaner recovery path than AF/G.22's (which relied on incidental subagent-transcript/scratch-disk persistence) and is worth remembering as the standard technique going forward: the orchestrating session's own transcript is a reliable place to recover dispatched-agent output after a compaction, as long as the transcript file itself is still on disk.

## Session conditions

Same evidence-strict standing rule as every prior AF session: verbatim quote + exact URL from a primary, government/agency-authored document for every claim; NOT FOUND is a legitimate, valuable outcome, recorded honestly in `_dropped` rather than left unmentioned. Each of the 14 synthesis agents was given: the raw research findings file path (`/tmp/rc-research/<country>.txt`) to read and transcribe from only — no new web research; the closed `Domain`/`JurisdictionLevel`/`DroppedReason`/`RelationshipType` enums; explicit warning, repeated verbatim from AF/G.22's own hand-off, that `reason: 'resolved'`/`'caveat'` require the named edge to actually exist in a `dependencies` array — the single most common near-miss error in this branch; and the existing per-country corpus context (node IDs, current `_dropped` notes) gathered by grep before dispatch, so agents could distinguish a genuine new node from an enrichment of an existing one.

## Headline result

All 14 countries now have genuine municipal/sub-national-tier (or, where a real structural absence was confirmed rather than assumed, explicitly-documented-absence) depth. **57 new report nodes, 29 new dependency edges, 107 new `_dropped` entries** across 14 new per-country files, plus enrichment edits (via the branch's standard `UPDATE [date] (AF/G.23, ...)` description-prepend convention) to 11 existing files. One schema error was caught and fixed during validation: a Gabon `_dropped` entry used `reason: 'note'` to describe an edge that (per a cross-file corpus check) genuinely exists in `af-cemac.json`'s live `dependencies` array — corrected to `reason: 'resolved'`, since the validator checks edge-existence corpus-wide, not just within the file being written. This is the same class of mistake AF/G.22 flagged (`caveat`/`resolved` needing a real edge) but its mirror image: here a real edge existed and the entry under-claimed it as `note` instead of over-claiming a nonexistent one as `resolved`/`caveat` — worth adding to the standing warning for future rounds.

`npm run validate` and `npm run build` both pass clean after the fix: **1047 reports, 952 dependencies, all 44 logic checks pass, 0 unwired slices** (206 slices via `npm run gen`'s auto-loader), `tsc --noEmit && vite build` succeeds. All 25 new/modified files were pushed to the device via `SendUserFile` + `device_commit_files` (`force: true` for the 11 modified pre-existing files); **nothing from this round is git-committed yet**, per the branch's standing rule.

### 1. Namibia — Local Authorities Act / Regional Councils Act transfer formula, plus a suspected systematic `.gov.na` block

Minted 3 nodes in `na-g23-municipal.json`: `na-local-authorities-act-1992` (s.77's 5%-of-property-rates local→regional transfer formula, s.80 fund structure), `na-regional-councils-act-1992` (s.33 regional-council fund structure), and `na-windhoek-strategic-plan-2022-2027` (City of Windhoek's own strategic plan, naming dependence on central-government CAPEX/subsidy without citing a specific statute — so no edge was drawn from it). ## Secondary observations

* **The orchestrating session's own transcript is a reliable compaction-recovery path.** Unlike AF/G.22 (which relied on incidental subagent-transcript/scratch-disk persistence and explicitly flagged that as non-guaranteed infrastructure behavior), this round located and read the session's own `.jsonl` transcript file directly, matched each research Agent tool call's `id` to its corresponding `tool_result` block, and extracted the raw findings text with a short Python script — a deliberate, repeatable technique rather than an incidental save. Worth using as the default recovery method (before assuming anything is lost) whenever a dispatch-then-synthesize session compacts between the two steps.
* **A new, subtler variant of the `_dropped.reason` mistake.** AF/G.22 flagged `caveat`/`resolved` used on a nonexistent edge as the branch's most common near-miss. This round's Gabon file made the mirror-image mistake: `reason: 'note'` on an edge that *does* genuinely exist elsewhere in the corpus. Both directions of this mistake matter and both are now documented — a synthesis agent needs to check not just "does my own file's `dependencies` array contain this edge" but "does the edge exist *anywhere in the corpus*," since cross-file edges (a node in one file, its dependency target minted in another) are common in this project.
* **Non-government hosting and technical-access workarounds were the norm, not the exception, this round.** At least 8 of the 14 countries required either an NGO/commercial mirror (Namibia's lac.org.na, Gambia's genderlinks-adjacent sourcing pattern seen elsewhere, Djibouti's droit-afrique.com/FAOLEX, São Tomé's cipstp.st), a TLS/certificate workaround (Eswatini's parliament.gov.sz `curl --insecure`), OCR of a scanned PDF (Gambia's NAO audit, Comoros's 2025 Loi de Finances), or a large-PDF timeout workaround (Seychelles' 799-page budget). This is now a well-established pattern across the whole AF branch, not specific to small/low-capacity states — worth keeping the technical-access-vs-content-absence distinction sharp in every future round, per the protocol's own instruction.

## How to write the next hand-off

(Copied verbatim per branch convention.)

Required sections, in this order: Orientation, Session conditions, Headline result, Findings (numbered `###` subsections, one per country/topic), Secondary observations, Corrections to prior sessions (never omit this section — even "none this session" is itself a claim, state it explicitly), Thomas's stated priority for the remaining work, Cheap checks still outstanding, What to pass at the start of next thread, and this spec block itself, copied verbatim into every hand-off.

Never edit a predecessor file. Corrections to earlier sessions go in the new file's Corrections section, dated and attributable to this session.

Every claim needs a document behind it — a URL/location and, wherever practical, a verbatim quote. "Comparable with"-type language is not a dependency. Tense matters: a PAST-tense arrangement is not a live dependency; flag it if a source's tense is ambiguous. AGENCY ONLY and NOT FOUND are legitimate research outcomes, not failures — record them in `_dropped` with an honest reason, don't leave the question unanswered and don't force an edge that isn't there.
