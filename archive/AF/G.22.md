## Findings

### 1. Sudan — National Audit Chamber SECRP audit (richest find of the round)

Minted `sd-nac-secrp-audit-2021` (federal, in `sd-g22-audit-chamber-fiscal.json`): Sudan's National Audit Chamber's audit of a World Bank-financed education grant (SECRP), itemizing named states (Central Darfur, North Darfur, West Darfur) and named localities within them (Umm Kadada, Baw) with specific financial figures — exactly the "higher-tier government reporting on named lower-tier units" pattern this branch treats as the richest municipal-tier evidence pattern. Sudan-government-authored despite being hosted on the World Bank's document server (same authorship-vs-hosting distinction already established for other countries in this branch). Also minted `sd-inc-2005-revenue-sharing`, the 2005 Interim National Constitution's state oil-revenue formula (Art. 192(5): "at least two percent of oil revenue... to the oil producing states"), explicitly flagged HISTORICAL/LIKELY SUPERSEDED given Sudan's subsequent constitutional rupture (2011 secession, 2019 Charter, 2021 coup, 2023 civil war) — included as a documented historical design fact, not current law. Sudan's National Audit Chamber's own domain (audit.gov.sd) is currently unreachable, and a UNICEF fiscal-impact report (non-primary, cited only for context) confirms federal-to-state transfers have been suspended by the civil war since March 2023 — the missing current state/locality tier appears to be a real, war-driven absence, not a research gap.

### 13. Cross-country poverty-line and minimum-wage verification (South Africa, Kenya, Tanzania, Ghana, Egypt, Nigeria, Ethiopia)

### 14. Rwanda/Uganda EAC-edge contradiction — resolved by retracting the live edges, not the dropped notes

The corpus contained a genuine internal contradiction: `rw-cpi-social-protection.json` and `ug-cpi-social-protection.json` each carried a correct, well-evidenced `_dropped` note (`reason: no-document`) stating that neither country's own CPI methodology cites the EAC's Harmonised CPI Regulations — while a separate file, `af-eac-wiring.json` (Round 4, 2026-08-12, part of "Thomas's Africa gap-filling test," not a numbered AF/G.* session), had nonetheless added **live dependency edges** `rw-nisr-cpi -> eac-hcpi-regulations` and `ug-ubos-cpi -> eac-hcpi-regulations` on the reasoning "both countries are confirmed EAC Partner States, and the EAC regulation obligates Partner States to submit a Harmonised CPI" — a same-region inference, not a textual citation. A dedicated re-verification round independently re-checked both countries' own official CPI methodology documents in full (NISR's September 2024 CPI bulletin; UBOS's July 2021 CPI publication with technical annex) for any EAC/HCPI mention — zero matches in either, confirming the pre-existing `_dropped` notes were right all along. **Fix applied**: both edges were retracted from `af-eac-wiring.json` (which now carries 0 live dependencies and 3 corrected `_dropped` entries, `reason: wrong-direction` — the EAC-obligation relationship is real, but runs from each country toward the EAC, not the reverse this edge asserted), and both countries' own `_dropped` notes were annotated in place with the 2026-08-13 re-verification record, without changing their `reason` (still correctly `no-document`) or claiming false certainty via `resolved`/`caveat`.

## Secondary observations

* **A dispatched-agent-output survival lesson, worth remembering.** This session's 14 pre-compaction research agents' full findings were recoverable only because subagent transcripts and scratch/downloaded source material happen to persist on the container's own disk across a compaction boundary within the same session — this is incidental infrastructure behavior, not a guaranteed feature, and it would not survive a full session end/restart. Anything a dispatched agent finds that isn't written to a durable file (a corpus JSON, a memory note) before the session ends is at real risk of being unrecoverable. A future session doing a large multi-agent research dispatch should consider having each research agent write its own findings to a scratch file immediately, rather than relying on the orchestrating session to synthesize everything in the same turn.
* **Two synthesis-agent schema mistakes, both caught by `npm run validate` rather than missed.** Two of the 13 synthesis agents used `reason: "caveat"` on `_dropped` entries that didn't actually name a live edge — the validator correctly rejects this (a `caveat` must point at a real edge; the DroppedReason documentation is explicit about this distinction from `note`). Both were one-line fixes once the validator flagged them by exact entry. Worth remembering that `_dropped.reason` selection is a common failure point for agents transcribing findings into schema, even when the underlying research is solid.
* **The `af-car-budget-decentralization.json` invalid-enum mistake (`"no-explicit-citation"`, `"wrong-target / non-primary"`) came from a pre-compaction agent working without the full `DroppedReason` enum in front of it.** This round's 13 synthesis agents were each given the closed enum list explicitly in their prompt and warned about this exact prior mistake as a negative example — none of them repeated it (the 2 `caveat` mistakes above were a different, subtler error: valid enum value, wrong semantic fit).

## How to write the next hand-off

(Copied verbatim per branch convention.)

Required sections, in this order: Orientation, Session conditions, Headline result, Findings (numbered `###` subsections, one per country/topic), Secondary observations, Corrections to prior sessions (never omit this section — even "none this session" is itself a claim, state it explicitly), Thomas's stated priority for the remaining work, Cheap checks still outstanding, What to pass at the start of next thread, and this spec block itself, copied verbatim into every hand-off.

Never edit a predecessor file. Corrections to earlier sessions go in the new file's Corrections section, dated and attributable to this session.

Every claim needs a document behind it — a URL/location and, wherever practical, a verbatim quote. "Comparable with"-type language is not a dependency. Tense matters: a PAST-tense arrangement is not a live dependency; flag it if a source's tense is ambiguous. AGENCY ONLY and NOT FOUND are legitimate research outcomes, not failures — record them in `_dropped` with an honest reason, don't leave the question unanswered and don't force an edge that isn't there.
