 2.1.1 Concepts and definitions To compile and disseminate data on Merchandise Trade, We follow the IMTS 2010. 2.3.1 Classification/sectorization Primary commodity classification is Harmonized Commodity Description and Coding System (HS Code) in addition the Standard International Trade Classification (SITC) is also used in EUROTRACE DBMS. 2.2.1 Scope Primary commodity classification is Harmonized Commodity Description and Coding System (HS Code) in addition the Standard International Trade Classification (SITC) is also used in EUROTRACE DBMS. Scope of the data The source is Customs based that records each and every external trade movement of the Rwanda Economic territory. Data on electricity are added up in order to have a complete database. Exceptions to coverage Goods under merchanting proved difficult to compile as these kind of data cannot be found on the customs database. 2.4.1 Valuation After all the customs data have been put together, some adjustments are made on exchange rates, c.i.f. values, etc. Sometimes, when problems are noted with the data, this information is once again cross-checked against the source data. 3.1.1 Source data collection programs For all publications, customs declarations serve as the primary source of information. All formal imports and exports are recorded by RRA (Rwanda Revenue Authorities), importers and exporters are requested to fill an import and export declaration form. The data from the declaration forms are keyed into ASYCUDA system, a computerized system designed by the United Nations Conference on Trade and Development (UNCTAD) to administer a country's customs. This system allows for rapid processing of the source data and the production of listings for control purposes. The data from the ASYCUDA system are uploaded into the EUROTRACE system at the National Institute of Statistics of Rwanda. NISR produces the merchandise trade statistics using EUROTRACE software. For classification purposes, the RRA uses the Harmonized Commodity Description and Coding System (HS Code). 3.1.3 Source data timeliness The customs office sends Asycuda-Eurotrace text files to NISR after every end of the month so as to allow the compilation of formal trade data and the writing of monthly, and quarterly trade reports. 3.2.1 Source data assessment Routine assessment is being done every time NISR receives the data from Customs so as to help get more clarifications on the suspected data inputs. 3.4.3 Assessment of discrepancies and other problems in statistical outputs Investigations of statistical differences are gathered each month against the additional information the Customs might have on a particular declaration to make clear the suspected outputs with tangible evidences.
