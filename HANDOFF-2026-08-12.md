## The visual system, as it now works

One idea, carried everywhere: **each family has one ink.** The ink is worn by
the node's fresnel rim, by every edge touching the family (gradient rim→rim,
so cross-family edges are two-tone), by the pulses riding those edges, and by
the family's chip in the chip bar. Fills carry level (dark→light down the
jurisdiction ladder, national darkest — Thomas's reversal); size carries
authority; the rim/edge ink carries identity.

- `src/lib/palette.ts` — the whole colour system. `COUNTRY_RIM` (the inks),
  `RIM_WEIGHT` + `rimWeightFor` (US bold red, EU thick lime, NZ/INT bold
  white, Africa lavender…), `BLUEPRINT_INK` + `blueprintInkFor` (dark
  printable ink per family for paper), `focusPalette` (single-family spread
  recolour), `COUNTRY_LABEL` (complete, all countries).
- `src/components/nodeVisuals.ts` — fresnel-rim material
  (`onBeforeCompile` on MeshStandardMaterial), `rimMax`/`litOpacity` in
  userData, hollow one-off instruments, orb band. `nodeGeometry` returns a
  sphere, always.
- `src/components/linkVisuals.ts` — gradient link shader (local z as the
  interpolant), per-material `litOpacity` (trunks), `setLinkFocus(material,
  lit, tracing)` — tracing lifts opacity and disables depthTest so a traced
  chain draws through nodes — and `setLinkDimTheme(blueprint)` for the
  out-of-focus colour/opacity pair.
- `src/components/InfluenceGraph.tsx` — the renderer. Trunk merging
  (parallel edges → one `LinkDatum` with `count`; width ×(1+0.45·log2 n),
  opacity ×(1+0.35·log2 n)), position-seeded rebuilds (`lastPositions`),
  the camera-fit machinery (read the comments before touching anything
  there — every guard is a documented bug), orb breath, focus pass.
- Blueprint mode (round 9): `view.blueprint` is the ONE view setting that is
  a `forceGraph` memo dep — flipping it rebuilds materials wholesale, with
  `lastPositions` seeding making the rebuild visually still. Paper
  background (as an OPAQUE `scene.background`, not just CSS — see invariant
  9), white discs pushed just past the paper tone so solid ≠ hollow,
  `blueprintInkFor` inks on rims/edges/pulses, fog forced off, bloom
  intensity zeroed (composer stays mounted), horizon unmounted, ambient
  raised to 2.6 (see invariant 9), blue fill light dropped, single-family
  recolour suspended, dim treatment themed (`PAPER_DIM_*` in view.ts: rim
  carries the ghost on paper, alpha carries it in the dark). Every number
  was tuned against screenshot pixel measurements, three cuts deep — the
  first two "obvious" values rendered concrete-grey discs and dim lines
  *brighter* than the paper.

## Invariants — do not relearn these the hard way

1. **Never reintroduce faceted node geometry while fresnel rims exist.**
   Flat faces have one normal each; the rim lights whole faces as they tilt
   ("rediculous" — Thomas, correctly). The tier-shape system died for this.
   The warning is written into `nodeVisuals.ts`; honour it.
2. **Every edge carries a document.** `evidence: 'implied'` is a validator
   ERROR. Retired implied edges live in
   `src/data/research/retired-implied-edges.json` with `_dropped` notes —
   they come back only by finding a real document, as new documented edges.
3. **No discontinued programmes in the corpus.** Ruling from round 2. When a
   programme dies, its node is deleted and its JSON preserved in project
   memory (see `discontinued-programmes-removed.md` for the TIF precedent).
4. **The camera-fit code is a minefield of fixed bugs.** `fitSync`,
   `userOwnsCamera`, `movedCamera`, the far-plane growth, the aspect-aware
   fit — each comment describes a measured failure. Read before editing.
5. **Mutate materials, don't rebuild meshes** for focus/recolour changes.
   The only sanctioned full rebuilds: `graph` identity (drilldown), `spread`
   (debounced), `view.blueprint` (round 9).
6. **three-forcegraph particles are NOT instanced** (verified in library
   source). Geometry and materials are cached per colour/size; draw calls
   scale with link count. Start any perf hunt from that fact.
7. **`import.meta.glob` is banned in data loading** — it would break the
   tsx-run validator. The slice loader is codegen: `scripts/gen-slices.ts`
   runs on pre-dev/pre-build/pre-validate.
8. **Height encodes nothing.** No vertical sorting force; position is edges
   only. Thomas has repeatedly declined "levels as altitude".
9. **Two rendering-pipeline facts that cost a morning, measured 2026-08-12:**
   (a) physically-correct lighting divides Lambertian diffuse by π, so an
   ambient light delivers about a third of its intensity to a white surface
   — light-theme numbers that "should" work render grey; and (b) with a
   transparent canvas over a CSS background, semi-transparent shader
   elements composite through a linear→sRGB conversion of alpha-weighted
   values, which lifts them nonlinearly — near-background tones blow out
   BRIGHTER than the background (blueprint's "dim" lines glowed white).
   Blueprint therefore sets an opaque `scene.background`; the dark theme
   deliberately keeps CSS compositing because all its tuning was done on
   it. Tune colours against screenshot pixels, never against arithmetic.
