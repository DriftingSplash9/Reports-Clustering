# EU proposals — draft holding area

Set up 2026-08-08 (OPEN-THREADS 1.8), after `G.52.md`'s three proposal files
were written to a session's `/tmp` and lost when that session ended —
fourteen of Thomas's answers in `notes/Decisions-2026-08-08_EU-open-questions.md`
now review artefacts that no longer exist. See `G.56.md` Finding 6.

**The rule this folder exists to enforce: a draft that is not in the repo
does not exist.** Any proposal file — for Thomas's review, for a future
session, for anything — gets written here, in the repo, the moment it
exists, even unfinished and even before it's reviewed. An unimported file
sitting in the working tree costs nothing. A file written only to a
sandbox `/tmp` costs a session, as it did here.

Nothing in this folder is imported or wired into `src/data/index.ts`.
Files move out once reviewed and either promoted (imported to
`src/data/research/`) or rejected — leave a one-line note in the file
itself, or here, saying which and when.
