# The 2026-08-20 mint — what the 37 `*-grok-2026-08.json` slices are

**Written 2026-09-05, sixteen days late.** Every one of the 37 slices carries
`meta.note: "… see notes/mint-2026-08-20.md"` and the file never existed
(Midvamp §10, Q18). This is reconstructed from the primary records that do
exist — `archive/Previous Handoffs/HANDOFF-2026-08-20-mint-fold-galaxy-isolate.md`
item 5 (written the day of the mint), the slices' own `meta` fields, and the
project-memory entry `grok_archive_state` — not from recollection. Where a
number below is not in one of those, it is counted from the slices today.

## What was minted

The consolidated Grok archive — 37 country files built 2026-08-18 from 293
Grok batch files (`Grok - Brics+israel and singapore/consolidated/`, a
folder that no longer exists in the repo; Grok itself is retired,
PLAYBOOK §5) — was merged into `src/data/research/` as one slice per
country plus `int-brics-international-layer-grok-2026-08.json`. Each slice's
`meta.source` names the consolidated file it came from.

Counted today: **1,668 reports · 463 dependencies · 545 `_dropped` entries**
across the 37 slices (the archive held 1,999 · 969 · 357 before the cuts
below). The live corpus went **1,250 → 3,091 reports, 1,079 → 2,070
dependencies** that day; `npm run validate` and `npm run build` exited 0 on
the merged corpus.

## The two rules the note was supposed to explain

**Live-wins dedup.** Every id collision between the archive and the existing
corpus was resolved the same way: the already-live node kept its definition,
the archive's copy was not minted. Not only the four named duplicates
(`in-mospi-cpi`, `in-rbi-balance-of-payments`, `ru-rosstat-cpi`,
`ru-cbr-monetary-policy-guidelines`) — uniformly. One field was grafted the
other way: RBI's `external-sector` domain tag onto the live
`in-rbi-balance-of-payments`.

**Scaffolding stripped.** Two shapes of non-publication had been minted as
report nodes by Grok and were excluded rather than shipped: about 25 *places*
(a Mexican state, an Argentine city — "Chiapas — core statistical identity")
and, in 12 other country files, *institutions* (central banks, statistics
offices), most already flagged in each file's own
`_gaps.institution_node_candidates`. About 53 nodes in all. One (`bo-ypfb`)
was independently flagged in the live corpus's own dropped notes, which is
how a near-repeat edge (`bo-alfabetismo → bo-educacion`, rejected once before
for weak evidence) was also caught and dropped.

## What the mint left behind — and where it went

- **URLs.** `check-urls` on Thomas's machine flagged 832 of 1,972 as dead;
  most were the plain HTTP client tripping bot-walls or TLS trust (Russian
  domestic CA). 37 were genuine 404s → `notes/stale-urls-2026-08-20.md`
  (now `_to_delete/notes-2026-09-05/`; the remainder closed 2026-08-29,
  memory `stale_urls_remainder_2026-08-29`). The checker itself was retired
  into the grader on 2026-09-05 (`npm run check-urls` → `grade-evidence.ts
  --urls`), which judges a wall as a wall and not as a dead link.
- **Density.** Thomas ran the shipped mint and found every tier but Global
  unusable at ~3,000 nodes — the per-country fold, galaxy force and isolate
  came the same day (item 5b of the 08-20 handoff).
- **Evidence.** The mint shipped Grok's edges with Grok's bases. The
  2026-08-30/31 audits found the hand-researched branches held and the Grok
  slices did not; 463 assertion-only edges went to `_dropped` on 08-31 and
  the grader (2026-09-03 →) found the Grok slices produced zero A grades at
  first grading. Raising those grades is the Midvamp Revamp programme.
- **Isolated nodes.** The mint predicted a halo of edgeless nodes and got
  one; the 2026-08-30 triage (memory `triage_2026-08-30`) classified all 793.
